[![Project Page](https://img.shields.io/badge/Project_Page-blue)](https://a-canela.github.io/instantavatar/)
[![arXiv](https://img.shields.io/badge/arXiv-2308.04868-b31b1b.svg)](https://arxiv.org/abs/2308.04868)

**TL;DR:** InstantAvatar combines a multi-resolution voxel-grid neural field with differentiable surface rendering and a learned 3D head SDF shape prior to reconstruct full-head avatars from one or a few images in seconds.

---

## 💻 Code <sub>(Not Available)</sub>

This work was conducted as part of an industrial research collaboration with **Crisalix Labs**. Consequently, the underlying source code and trained models are proprietary assets of **Crisalix SA** and cannot be made publicly available.

This repository only hosts the project page for the publication. For further technical details regarding the architecture, training schedule, and evaluation setup, please refer to the [paper on arXiv](https://arxiv.org/abs/2308.04868).
